# authentication-evolution-guide
### What makes this repository different?
Instead of saying
```
"JWT is used for APIs"
```
each chapter answers:
```

Why was the previous method not enough?

↓

What security problem existed?

↓

How was it solved?

↓

What new problems were introduced?

↓

How does the next authentication method solve those?
```

## Example Chapter Layout
Every chapter can follow the same structure.
```
1. History

2. Problem

3. Security Issues

4. Architecture

5. Python Example

6. HTTP Request

7. HTTP Response

8. Attack Example

9. Solution

10. Advantages

11. Disadvantages

12. Real World Usage
```
